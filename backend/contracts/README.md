# Internal service contracts

Each child module owns generated, framework-neutral Kotlin wire models for one service boundary.

- The source of truth is `src/main/openapi/openapi.yaml` in the owning contract module.
- Kotlin is generated only under `build/generated/openapi`; generated sources are never checked in or edited manually.
- Provider and consumer modules depend on the same generated model jar and keep transport, authentication, timeout, and error translation in local adapters.
- Public facade contracts remain under the repository-level `contracts/` directory and are not generated by these modules.
