# Document viewer fixture

`pdf-display-sanitized.pdf` is the display derivative produced on DEV by
`MaterialDocumentPreparationService` from the synthetic PDF generated by
`frontend/web-app/scripts/generate-document-viewer-fixtures.py`. It contains
only three synthetic page labels. Its SHA-256 is
`46985528e34f1c065c43c305e36685c19c2074c834d48878c93406836fe686bb`.

The browser smoke copies it into the generated viewer fixtures so the viewer
opens sanitized bytes, rather than the uploaded source PDF.
