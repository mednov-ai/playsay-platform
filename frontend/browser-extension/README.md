# Расширение Honey.school

Расширение позволяет учителю показывать внешнее интерактивное задание участникам общего урока Honey School. Поддерживаются Google Chrome и Microsoft Edge версии 116 или новее.

## Готовая сборка из `develop`

Каталог `browser-extension/dist` хранится в ветке `develop` уже собранным. После клонирования или обновления репозитория его можно сразу выбрать через **Загрузить распакованное расширение**. Пересобирать расширение нужно только после изменения исходников.

## Сборка

Из каталога `playsay-platform/frontend` выполните:

```bash
npm ci
npm --workspace browser-extension run package
```

Команда создаст:

- распакованное расширение в `browser-extension/dist`;
- архив `browser-extension/playsay-browser-extension.zip`.

## Установка из `develop`

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите каталог `playsay-platform/frontend/browser-extension/dist`.
5. Закрепите кнопку с пчёлкой через меню расширений браузера.

Важно: не выбирайте каталог `browser-extension`. Chrome загружает только каталог, в корне которого находится готовый `manifest.json`; в репозитории это каталог `dist`.

## Установка из Jenkins ZIP

1. Скачайте артефакт `playsay-browser-extension.zip`.
2. Полностью распакуйте архив в отдельный постоянный каталог.
3. Откройте страницу расширений и включите режим разработчика.
4. Нажмите **Загрузить распакованное расширение** и выберите распакованный каталог. В его корне должны лежать `manifest.json`, `service-worker.js` и `content-script.js`.

Не удаляйте и не перемещайте этот каталог после установки: браузер использует файлы прямо из него.

## Обновление

1. Пересоберите расширение или замените содержимое распакованного каталога новой версией.
2. Откройте страницу расширений.
3. Нажмите кнопку **Обновить** на карточке Honey.school.
4. Убедитесь, что отображается версия `0.1.6`.

Если старое расширение было загружено из неправильного каталога, удалите его карточку и установите заново из `dist`.

## Ошибка `Manifest file is missing or unreadable`

Ошибка означает, что выбранный каталог не содержит читаемый `manifest.json` прямо в своём корне.

- Для исходников выберите `browser-extension/dist`, а не `browser-extension`.
- Если `dist/manifest.json` отсутствует, обновите ветку `develop` или снова выполните команду сборки.
- Для Jenkins ZIP сначала распакуйте архив целиком и выбирайте распакованный каталог, а не сам ZIP.

## Запуск совместного задания

1. Откройте внешнее задание из общего (`SHARED`) урока.
2. Браузер откроет сайт задания в новой вкладке.
3. В этой вкладке нажмите закреплённую кнопку расширения с пчёлкой.
4. Разрешите браузеру начать показ. Расширение вернёт учителя в урок автоматически.

Расширение использует временный доступ `activeTab`, захват вкладки и MAIN-world input bridge. Разрешение `debugger` не запрашивается, поэтому системная панель Verify/Debugging появляться не должна.

## Разрешённые сайты Honey School

- `https://dev.online.honey.school`
- `https://online.honey.school`
- `https://online.honeyschool.ru`
- `http://localhost` и `http://127.0.0.1` для локальной разработки

Расширение не получает постоянное разрешение на остальные сайты. Вкладка внешнего задания доступна только после явного действия учителя.
